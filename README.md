# PauloEats 🍽️

A modern Food/Restaurant App for discovering, browsing, and ordering from restaurants.

## Features

- 🔍 Browse restaurants and food items
- 🛒 Shopping cart functionality
- 📱 Responsive design
- ⭐ Restaurant ratings and reviews
- 🚚 Order tracking
- 💳 Payment integration

## Tech Stack

- **Frontend**: React, Tailwind CSS
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Authentication**: JWT

## Getting Started

### Prerequisites

- Node.js (v16+)
- npm or yarn
- MongoDB

### Installation

```bash
# Clone the repository
git clone https://github.com/ocir95/pauloeats.git
cd pauloeats

# Install dependencies
npm install

# Setup environment variables
cp .env.example .env

# Start the development server
npm run dev
```
